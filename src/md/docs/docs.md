## What is this website?

Obviously, the core of this website is the games. It's what most people come here for. Its other purpose, at least for me, is a passion project. I love to code, and I love to share my creations with others. When I add a new feature, it's a sign that I've learned something new. I haven't done anything like this in my past, except when I was distributing .zip website files to classmates in middle school (shoutout to the homies who've been here since grandview-unblocked).

The purpose of the Docs is to teach you something new. Most pages, including the entirety of the docs uses a language called [Markdown](https://www.markdownguide.org/getting-started/), which will be used for any coding tutorial or documentation page for the sake of simplicity. This simplicity allows me to pack a lot of information into this website with minimal work.

## Why the :3000?

The usual answer I give for this is "so that the website stays unblocked", but I realize that such an explanation doesn't really give you the big picture. When a :3000 is added at the end, that symbolizes that you, the client, want to connect to the 3000th port of the server described by the URL. Without getting into too much technical detail, computers have something like 60,000 ports that you can open up to the public so that others are able to connect to them. In this case, the 3000th port leads to this website.

Here's the crazy part - that unblockable property of the 3000th port was discovered by accident. My guess is that the school's unblocker doesn't check any ports that aren't normally used for websites (80 for HTTP and 443 for HTTPS). If you decide to make a website and you want it to be able to run it on a school chromebook, I would recommend using the :3000 method.

## History of the site

As you might have guessed from earlier, the first version of this site was grandview-unblocked. It was very minimal but had a superior version of Tetris that I still can't seem to find. Hosting the website was, and forever will be, the hardest part of making websites for school use (see *Make Your Own Website* to see why). That was why it was a .zip file that was hosted on a Google Site.

The site as we know it today started out as a way to share answers to worksheets with my classmates. Each webpage was behind a "code", which I thought was was a good way to ensure the secrecy of the website (it wasn't). Eventually I started hiding games behind these codes, leading to the idea of having one code for all of the games. This eventually caused some problems with form resubmission, which made me restructure the website into what we know and love today.

The addition of the Minecraft server was very difficult. Finding the now copyrighted files was difficult because of their rarity on the internet. Once I practically collected them like Infinity Stones, I had to create the minecraft server itself, which was definitely the hardest part. Linking the client and the server was the biggest pain in the butt. Fortunately, I have already crossed that bridge for you, and you shouldn't have too much trouble with it if you decide to follow my tutorial.
